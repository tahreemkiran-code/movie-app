# 🎬 Movie App

A modern and responsive **Movie Search Application** built with **React.js**, **Vite**, and **CSS**. This app allows users to search for movies, view detailed information, and explore trending movies using the **OMDb API**.

---

## 🚀 Features

- 🔍 Search movies by title
- 🎥 View movie posters
- ⭐ Display movie title, year, and type
- 📱 Fully responsive design
- ⚡ Fast performance with Vite
- 🎨 Clean and modern UI
- 🔄 Dynamic API integration
- ❌ Handles "Movie Not Found" results

---

## 🛠️ Technologies Used

- React.js
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3
- OMDb API

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/tahreemkiran-code/movie-app.git
```

Navigate to the project folder:

```bash
cd movie-app
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

---

## 🎯 How It Works

1. Enter a movie name in the search bar.
2. Click the **Search** button.
3. The app fetches movie data from the **OMDb API**.
4. Browse movie cards showing posters, titles, years, and types.
